# Локальный ИИ-агент

Агент работает из корня Rails-проекта. Он может подготовить изменения для файлов в `ai_agent/` (свой код) или `app/` и `test/` (магазин). Перед отправкой кода на Groq проверь, что в выбранных файлах нет секретов.

Добавь новый ключ `GROQ_API_KEY` в локальный `.env` или окружение, затем запускай генерацию:

```sh
bin/agent improve --scope agent --files ai_agent/lib/code_agent.rb -- "Улучши обработку ошибок"
bin/agent improve --scope store --files app/services/ai_service.rb,test/services/code_agent_test.rb -- "Добавь обработку тайм-аута"
```

Агент покажет diff и спросит подтверждение. Для применения сохранённого предложения используй `bin/agent apply PROPOSAL_ID`.

Веб-интерфейс доступен по `/agent` после входа в приложение. Он также требует подтверждения перед применением. После изменений самостоятельно проверь код и запусти тесты (`bin/rails test`); агент не выполняет команды, сгенерированные моделью.
